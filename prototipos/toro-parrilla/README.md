# Protótipo — Toro Parrilla e Bar

Redesign do site `toroparrillaebar.com.br`, feito a pedido do dono e usando como base
uma gravação de tela do site atual (a marca preta e dourada foi mantida; a estrutura
foi refeita).

- `index.html` — protótipo completo em um arquivo, sem dependências externas.
  Abre direto no navegador.

Não faz parte do produto GastroMundi: é uma peça de apresentação, mora aqui só para
não se perder. O conteúdo veio do site atual e de fontes públicas — **preços, fotos e
horários precisam ser confirmados com a casa** antes de qualquer uso real.

O que o redesign resolve: o site atual não tem cardápio, horário, reserva nem rota.
Aqui a primeira dobra pergunta "o que você quer fazer agora?" (reservar, ver o cardápio,
chegar), o horário aparece como estado ao vivo ("Aberto agora · fecha às 23h"), o
cardápio tem filtro por gosto para quem não conhece os cortes, e a reserva monta a
mensagem de WhatsApp mostrando o texto antes de enviar.
