# `ui/botoes/` — botões compartilhados

Pasta reservada, ainda vazia. Hoje o projeto usa `<button>` inline nas telas e não há
nenhum botão extraído para uso em mais de um domínio.

Coloque aqui um botão quando ele for usado por **dois ou mais domínios**
(ex.: um `BotaoPrimario` do design system). Botão que serve a uma feature só fica em
`src/components/<dominio>/botoes/` — como `components/fiscal/botoes/BotaoReimprimirNfce.jsx`.

Critério completo em [`src/LEIAME.md`](../../../LEIAME.md).
