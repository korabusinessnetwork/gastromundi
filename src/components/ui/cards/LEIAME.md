# `ui/cards/` — cards compartilhados

Pasta reservada, ainda vazia. Hoje os cards são montados inline dentro de cada tela e
nenhum foi extraído para uso em mais de um domínio.

Coloque aqui um card quando ele for usado por **dois ou mais domínios**
(ex.: um `CardMetrica` do design system). Card que serve a uma feature só fica em
`src/components/<dominio>/cards/` — como `components/financeiro/cards/ResumoCards.jsx`.
